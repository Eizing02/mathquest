# หน้านักเรียนแบบกระชับและติดตั้งบนหน้าจอโฮม

งานปรับ UI ตามแผนวันที่ 29 ตุลาคม 2569 ตรวจยืนยันต่อวันที่ 30 ตุลาคม 2569

## ขอบเขต

ปรับหน้าหลักนักเรียน การกรอก PIN การแสดงผลเช็คชื่อ หน้าต่างย่อย และคำแนะนำติดตั้งแอป ไม่ต้องรัน SQL เพิ่ม ไม่มี dependency ฝั่งเว็บใหม่ และไม่มี Service Worker หรือการเช็คชื่อออฟไลน์

ไม่เปลี่ยนกติกาคะแนน เหรียญ สัตว์เลี้ยง การแลกของ รายงาน ScanSob หรือการตัดสินตำแหน่งจาก Supabase การแก้รหัสนักเรียนและงานอัปเดตสกิลที่ค้างอยู่ไม่รวมในงานนี้

## หน้าหลัก

- รูปพร้อมกรอบ ชื่อ ห้อง ภาคเรียน และรหัสนักเรียนอยู่ส่วนบน
- Level, XP และยอดเหรียญแสดงแบบกระชับ ไม่ใช้วงเลเวลขนาดใหญ่ซ้ำกับรูป
- ใช้ภาพสัตว์เลี้ยงและกรอบเดิม กดลูกศรเพื่อดูสิทธิ์เปลี่ยนตัว เปลี่ยนชื่อ และความสำเร็จ
- เมนูล่างเป็นหน้าหลัก ร้านค้า คะแนนสอบ และประวัติ คะแนนสอบยังขึ้นตามสิทธิ์เดิม
- เมนูเพิ่มเติมรวมบัญชี Google รีเฟรช วิธีติดตั้ง และออกจากระบบ
- การแจ้งเตือนของขวัญยังใช้ระบบเดิม ปรับเฉพาะขนาดและตำแหน่ง ไม่เปลี่ยนกติกาการอ่าน

พื้นที่เนื้อหากว้างสูงสุด 480px ใช้ Sarabun ตามโครงการ สีเขียวเน้นการเข้าเรียน สีทองเน้นเหรียญ สีแดงใช้แจ้งข้อผิดพลาด ค่าที่ใช้ในหน้านี้ไม่ได้ถูกยกระดับเป็นมาตรฐานใหม่ของทั้งโครงการ

เป้าหมายหน้าแรกคือเห็นปุ่มเช็คชื่อเหนือเมนูล่างที่ขนาดโทรศัพท์ทั่วไป จอเตี้ย 320x568 การเปิดคีย์บอร์ด ชื่อยาว หรือข้อความขนาดใหญ่ยอมให้เลื่อน ไม่บีบข้อความหรือซ่อนเนื้อหาสำคัญ

## PIN สี่กล่อง

ใช้ `#pinCode` เป็น input จริงเพียงช่องเดียว และแสดงตัวเลขผ่านสี่กล่องที่ไม่ซ้ำใน accessibility tree รองรับคีย์บอร์ดตัวเลข วางรหัส เลขศูนย์นำหน้า เลขไทยที่แปลงเป็นเลขอารบิก และแตะเลือกตำแหน่งเพื่อแทนเลข

กรอกครบแล้วต้องกดเช็คชื่อหรือ Enter ไม่ส่งอัตโนมัติ ระบบเดิมยังตรวจคาบ PIN ห้อง ตำแหน่ง และคำขอจากเซิร์ฟเวอร์ ป้องกันการส่งซ้ำระหว่างรอผล

| ผล | การตอบรับ |
| --- | --- |
| ไม่ครบสี่หลัก | แจ้งให้กรอกครบ ไม่เรียกบันทึก |
| PIN ผิด ไม่มีคาบ หมดอายุ ผิดห้อง หรือคาบเปลี่ยน | กล่องแดง สั่นสั้น และข้อความเฉพาะสาเหตุ |
| GPS หรือเครือข่ายมีปัญหา | แจ้งสาเหตุโดยไม่ตีความว่า PIN ผิด |
| เซิร์ฟเวอร์ยืนยันสำเร็จ | กล่องสีเขียวเคลื่อนเป็นคลื่น พร้อมคะแนนจริง |
| มีข้อมูลเช็คชื่อแล้ว | แจ้งว่ามีข้อมูลแล้ว ไม่จำลองว่าได้คะแนนเพิ่ม |

เอฟเฟกต์คืนสภาพปกติใน 3 วินาที ข้อความยังอยู่ให้อ่าน หลังสำเร็จจึงล้าง PIN หากผู้ใช้ยังไม่ได้เริ่มแก้ไขใหม่ โหมดลดการเคลื่อนไหวใช้สีและข้อความแทนการสั่นหรือคลื่น

ช่องและตัวเลขขยายตามขนาดข้อความ ผลตรวจถูกเลื่อนให้เห็นเหนือเมนูล่างหรือพื้นที่คีย์บอร์ดเมื่อจำเป็น ไม่มีการจัดเก็บ PIN หรือพิกัดเพิ่มใน localStorage

## ปุ่มติดตั้ง

ชื่อแอปคือ **เช็คชื่อเข้าเรียนครูอี้** ใช้โลโก้เดิมจาก `apple-touch-icon.png` ต้นฉบับไม่ถูกเขียนทับ

- ปุ่มเล็กมุมล่างขวาอยู่เหนือเมนูอย่างน้อย 8px ตรวจการชนกับ PIN ข้อความ ตำแหน่ง และปุ่มเช็คชื่อ
- หากไม่มีพื้นที่ว่าง ซ่อนปุ่มลอย แต่ยังเปิดคำแนะนำผ่านเมนูเพิ่มเติมได้
- ซ่อนระหว่างกรอก PIN เช็คชื่อ เปิดหน้าต่าง มี toast ของขวัญ หรือเมื่ออยู่โหมดแอป/ได้รับเหตุการณ์ติดตั้งจริง
- คำแนะนำเป็นแผงด้านล่างบนมือถือ เลือก Android หรือ iPhone/iPad ได้ พร้อมไอคอน Font Awesome และข้อความจริง ไม่ฝังตัวหนังสือในภาพ
- Android แสดงปุ่มติดตั้งเฉพาะเมื่อได้รับ `beforeinstallprompt` ใช้ event ได้ครั้งเดียว หากไม่มี event หรือยกเลิก แสดงวิธีผ่านเมนู Chrome
- iPhone/iPad แนะนำ Safari และเมนูแชร์เพื่อเพิ่มไปยังหน้าจอโฮม ไม่อ้างว่าสั่งติดตั้งอัตโนมัติได้
- การยอมรับ prompt เป็นเพียงการยืนยันคำขอ ไม่ถือเป็นหลักฐานว่าติดตั้งเสร็จแล้ว

Manifest ใช้ `standalone` และ origin เดียวกับเว็บ ไอคอนมีขนาด 180/192/512px และ maskable 512px ย่อจากต้นฉบับด้วย Sharp พร้อมจานสีสูงสุด 256 สีและข้อมูลที่มาฝังใน PNG การติดตั้งยังต้องใช้อินเทอร์เน็ต Google Login และอนุญาตตำแหน่งตามเดิม ไม่เพิ่ม push notification เบื้องหลัง

## การปิดหน้าต่าง

- แตะพื้นหลังนอกหน้าต่างเพื่อปิด พื้นที่ว่างภายในไม่ปิด
- ร้านค้าและเลือกสัตว์เลี้ยงตรวจว่าการแตะเริ่มจากพื้นหลัง ไม่ถือการลากจากข้างในเป็นการปิด
- หน้าต่างซ้อนปิดทีละชั้น ไม่ให้การแตะทะลุไปยังปุ่มด้านหลัง
- การแก้กรอบ ครอปรูป และชื่อสัตว์เลี้ยงมีการป้องกันทิ้งการแก้ไขโดยไม่ตั้งใจ
- หน้าครอปรูปเปิดใช้ backdrop ปกติ แต่ยังกันปิดระหว่างประมวลผล และการยกเลิกไม่อัปโหลดรูป
- คำถามทิ้งข้อมูลระงับ focus trap ของ Bootstrap ฝั่งแม่ชั่วคราว แล้วคืนเมื่อกลับไปแก้ไข คงปุ่มปิดและ Escape
- หน้าประวัติโหลดแบบปิดได้ ผลตอบกลับหลังปิดหรือเปลี่ยนบัญชีจะไม่เปิดหน้าต่างกลับมา

Bootstrap ถูกตรึงไว้ที่ 5.3.0 การประสาน focus trap ใช้ `_focustrap` ภายในไลบรารี หากอัปเกรด Bootstrap ต้องรันทดสอบ Tab/Escape/คืนโฟกัสซ้ำ

## ไฟล์หลัก

- `student-home.js` / `student-home.css`: layout, PIN, แผงเมนู และการปิดหน้าต่าง
- `student-install.js` / `app.webmanifest` / `assets/app-icons/`: ติดตั้งและไอคอน
- `index.html`: โครงสร้างหน้าและลำดับโหลดไฟล์
- `app.js`, `google-auth.js`, `attendance-location.js`, `profile-frames.js`: จุดเชื่อม UI แบบจำกัดขอบเขต
- `scripts/serve.cjs`: รองรับ MIME ของ `.webmanifest` ในเซิร์ฟเวอร์ทดสอบ

## เปิดทดสอบและเผยแพร่

เปิดเซิร์ฟเวอร์ด้วย `node scripts/serve.cjs 5173` แล้วเข้า `http://127.0.0.1:5173/` เลือก Guest เพื่อดูข้อมูลจำลองโดยไม่ตั้งค่า Google สำหรับ localhost

การเผยแพร่เป็นไฟล์ static ตามขั้นตอนเดิม ไม่ต้องเพิ่ม SQL หรือ Secret เมื่อขึ้น HTTPS แล้วต้องตรวจการติดตั้งจริงและ Google Login จากไอคอนบน Android/iPhone/iPad อีกครั้ง บางเครื่องอาจต้องเข้าสู่ระบบใหม่เมื่อเปิดเว็บแอปครั้งแรก

ดูผลทดสอบและข้อจำกัดใน [รายงาน QA](20261029-student-mobile-ui-qa.md)

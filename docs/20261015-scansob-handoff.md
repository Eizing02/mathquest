Wire profile: schema_version 1.0, strict source score schema, 256 KiB max, 100 results/batch and 100 batches, processed/stale_ignored ACK with exact issue accounting. Matching uses text student codes and destination roster only. Revisions remain scoped by school/Workspace/exam across re-pairing. Exact-byte hashes, frozen ACKs, manifest conflicts and transactional commit-before-200 are enforced. No XP/coin side effects.

Pairing: 16 uppercase hexadecimal characters, single-use, 10-minute expiry. Pending request expires after 24 hours. Teacher approval is required. Approved delivery is recoverable for 24 hours. Stable per-request HMAC-derived token is reconstructed under authenticated status requests; DB stores hashes only. This avoids both stored plaintext and rotating a token on each status retry. Review this delivery choice jointly before enabling. Active bearer revoke returns the specified revoked acknowledgment and is safely retryable, including after teacher revocation. A dedicated rotate handshake remains unimplemented; use revoke/re-pair.

Visibility: teacher can inspect partial batches and held history. Students require a matching active publication/score connection and complete current batches. Approval of a replacement cannot resurface old rows. Same-lifecycle additive omissions remain unchanged. A lost ACK retry never duplicates results. Fix unmatched codes with a NEW publication revision; original ACKs stay immutable.

Term reset: imported scores and student-bearing receipts are permanently deleted, connections revoked, control watermarks/minimal purge evidence retained, and imported/current terms closed. Closed publication returns HTTP403 TERM_CLOSED, which source 011 recognizes. An authenticated higher withdrawal may obtain the ordinary processed ACK only when a matching actual purge is verified. Source 011 must allow that explicit withdrawal through its closed-term dispatch gate; it must not infer successful withdrawal from TERM_CLOSED.

Routine reset still requires active Workspaces to finish withdrawals first. Emergency admin revoke stays immediate. Source SQL 011 implements a distinct paused recovery which retains historical delete guards; receiver 03 supports its exact revoke ACK and protects old score visibility during re-pair. MathQuest has not edited the source repository or reopened revoked ingestion tokens.
